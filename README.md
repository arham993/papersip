# Papersip Company

Website for Papersip Company, a one-stop advertising agency in Faridabad running TV, radio, print, OOH and digital advertising, visibility signage, media buying & planning, and strategy. In business since 2010.

- Single self-contained `index.html` (no build step)
- 3D paper-craft media set built with Three.js r128, smooth scrolling with Lenis
- Light and dark themes, responsive down to phone width, respects reduced-motion

## Go live with GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
The site then publishes at `https://arham993.github.io/papersip/`.
